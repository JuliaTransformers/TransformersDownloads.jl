TransformersDownloads.jl

TransformersDownloads.jl downloads model files from the Hugging Face Hub or reads them from local paths, and returns them as Julia data: config.json, SafeTensors and PyTorch weight files, tokenizer.json, vocabularies and merges.txt.

The package contains no model or tokenization code; model architectures live in packages such as DistilBERT.jl, and tokenization algorithms are planned for a separate TransformersTokenizers.jl package.

Features

  • Hugging Face Hub integration: download and cache files by repository id.
  • SafeTensors first: memory-mapped, zero-copy weights, including sharded checkpoints via a lazy ShardedStateDict.
  • Legacy support: PyTorch Pickle (.bin) weights through the optional Pickle.jl extension.
  • Local paths: directories or specific files, with clear errors when something is missing.
  • Extensibility: vocab_format, load_vocab_file and load_pickle_weights are documented extension points.

Installation

Requires Julia 1.10 or later (package extensions).

using Pkg
Pkg.add("TransformersDownloads")

Quick start

using TransformersDownloads

# Tiny model keeps the examples light; swap in any Hugging Face repository id.
model_id = "hf-internal-testing/tiny-random-bert"

config    = load_config(model_id)
weights   = load_weights(model_id)
vocab     = load_vocab(model_id)
tokenizer = load_tokenizer(model_id)

Every load_* function accepts a local directory or a direct file path in place of a repository id:

config  = load_config("./my_model")
weights = load_weights("/path/to/custom_weights.safetensors")

TransformersDownloads.TransformersDownloads — Module
module TransformersDownloads

A Julia package for downloading and loading Transformer model configurations and weights from the Hugging Face Hub or local directories.

Support for SafeTensors is built-in, while PyTorch Pickle format is supported via the Pickle.jl extension.

TransformersDownloads.AbstractSource — Type
AbstractSource

Supertype describing where an asset comes from: a Hugging Face Hub repository (RepoSource) or a local file/directory (PathSource).

The public API accepts a plain string for repo_id; the string is classified once with classify_source and all internal logic dispatches on the resulting source type. Advanced users can construct a source explicitly and pass it to load_* functions to bypass classification.

TransformersDownloads.ShardedStateDict — Type
ShardedStateDict <: AbstractDict{String, AbstractArray}

Lazy dictionary-like view over a sharded SafeTensors checkpoint (model.safetensors.index.json). Tensor bytes remain memory-mapped in the per-shard SafeTensor objects; only the index (parameter name to shard) is held in memory.

Supports the full AbstractDict interface (keys, values, getindex, haskey, iteration, length).

TransformersDownloads.classify_source — Method
classify_source(x::AbstractString) -> AbstractSource

Classify x as a local [PathSource] or a remote [RepoSource]:

  • an existing file or directory is a PathSource;
  • a string that looks like a path (/..., ./..., ~/...) but does not exist throws a PathNotFoundError instead of being sent to the Hub;
  • anything else is treated as a Hugging Face repository id.

To force a relative path that does not start with . or ~ to be treated as a local path, prefix it with ./.

TransformersDownloads.ensure_possible_files — Method
ensure_possible_files(possible_files, repo_id; revision=nothing,

Return the names of the files available in repo_id, which may be a Hugging Face repository id, a local directory or a local file.

If possible_files is not nothing it is returned unchanged, allowing callers that already know the repository contents to skip the remote listing (and its network round trip).

TransformersDownloads.hf_file — Method
hf_file(repo_id, filename; revision="main", kws...) -> String

Return the local path of filename inside repo_id.

repo_id may be

  • a Hugging Face repository id such as "google-bert/bert-base-uncased", in which case the file is downloaded (and cached) on demand;
  • a path to a local directory containing filename; or
  • a path to a local file, in which case that file is returned directly, regardless of filename (useful for files with non-standard names).

A string that looks like a path but does not exist throws a PathNotFoundError instead of being sent to the Hub as a repository id.

Supported keyword arguments are revision, auth_token, cache and local_files_only (the latter two are only meaningful for remote files).

TransformersDownloads.load_weights — Method
load_weights(repo_id; possible_files=nothing, kws...) -> AbstractDict{String, <:AbstractArray}

Load the weights (state dictionary) for a given repository ID or local path.

The available format is detected automatically, prioritizing SafeTensors over PyTorch Pickle (.bin), the latter requiring Pickle.jl to be loaded.

The returned object maps parameter names to tensor arrays and is always an AbstractDict{String, <:AbstractArray}:

  • a SafeTensors.SafeTensor for a single model.safetensors file. The arrays are memory-mapped views, so tensor data is not copied into RAM;
  • a ShardedStateDict for sharded checkpoints (model.safetensors.index.json), a lazy view over the per-shard files;
  • a Dict{String, Any} for PyTorch Pickle checkpoints.

Consumers should rely on the AbstractDict interface rather than on the concrete return type.

source
TransformersDownloads.vocab_format — Method
vocab_format(name::AbstractString) -> Union{Nothing, Symbol}

Determine the vocabulary format from a file name. Returns :txt for .txt files, :json for .json files, or nothing when the format is unknown.

This is an extension point. To support a new vocabulary format, define a vocab_format method for your own string type (avoiding type piracy on String) and a matching load_vocab_file method.
